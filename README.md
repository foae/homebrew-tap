# Foae Homebrew tap

Maintainer-owned formulae for Foae tools.

## Plane CLI

```sh
brew install foae/tap/plane-cli
plane-cli --help
```

Supports Linux and macOS on amd64 and arm64. Formula checksums refer to the published [Plane CLI release assets](https://github.com/foae/plane-cli/releases).

See the [Plane CLI quickstart](https://github.com/foae/plane-cli#first-request) for connections and authentication.

```sh
brew upgrade foae/tap/plane-cli
brew test foae/tap/plane-cli
```
